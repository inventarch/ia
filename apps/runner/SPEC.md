# Local execution runner

`@inventarch/runner` composes the agent-system Engine, session-system SQLite JournalStore and replay reducer, the composition compiler and execution manifest, and the runtime Door. `openRunner` selects exactly one admitted profile, entry and harness in a clean workspace. It captures native source once, compiles installed contracts, and verifies the capture and implementation pins before subsequent execution. Native source never selects an import, executable or credential.

The local host installs the first-party captured-source read only. Its binding is joined through `bindExecution`; the installed adapter independently verifies compiled closure, source revision, current grant and implementation bytes before and after reading. Unknown bindings fail closed. The built-in grant permits read effects only, and intersecting host and authored mandate limits are enforced by Engine resource accounting. Applicable mandate moves and excluded words are checked before operation dispatch; a refused action records a stable refusal code and next command. Additional host authorization can narrow, never widen, the local ceiling. Required evaluators are unavailable unless the host installs their callback.

Every model turn requests a phase-specific `position` through Door. Source membership, read effect and Observation mandate permission are required before creating a packet and again before calling the model transport. Current permission is intersected with the authority retained when the session started. The packet key, body and host note are retained in the model request journal. Model transport clears compiler-flattened instructions and voice; current position delivery supplies teaching. Source bodies are disclosed only through the separately verified, journaled `read-captured-source` operation. This host exposes no additional navigation or direct read API. The profile's installed context contract determines shape and record budget; grant limits further bound depth, budget and total request bytes.

Operation dispatch also applies mandates covering the requested source path. Their limits are checked against the original session's cumulative counters and deadline before preparing the operation and again at the installed reader's authority checks. A read reserves its installed output ceiling and journal envelope within the applicable byte limit. A path-specific limit cannot reset accounting or renew time when a run resumes. Refusals retain a stable code and next command in the durable journal.

`start` writes the session start before returning. `step` advances one scheduler action, and `run` stops at terminal state, a persisted wait, or its bounded scheduler count. Journals live under `.ia/work/runs/` with session-system's ownership, WAL durability and hash-chain replay. Resume requires the original principal, executable manifest and source capture. Limits retain their original deadline; resume does not renew or reset them. A deferred model stores an exact pending request, and `submit` consumes one response through Engine's external-model protocol. CLI output is structured JSON; no live provider is selected.

Runtime evidence records are derived from the durable journal and admitted at band 0 by the database's runner evidence verifier. Receipts live in `.ia/work/runner-evidence/`, separately from validation-owned evidence. The native `@run` records the journal and its profile's agent as owner; its status and phase say `recorded`, explicitly referring to the evidence rather than claiming the Engine's live state. The API's replayed session supplies live state. Observations describe recorded operation outcomes, terminal outcomes and waits, with the run as subject, an evaluator, move, verdict and snapshot revision. They cannot replace authored records, modify mandate authority, or move the authored revision. A failed evidence write fails the runner call after preserving the durable journal, so resume can retry projection. Runtime files are local evidence; they are neither committed source nor release artifacts.

Qualification: `tests/runner.test.ts` exercises the conformance composition, allowed captured read, limit refusal, mandate refusal, per-turn position injection, SQLite replay, deferred response resume and stale capture refusal. Package build and typecheck qualify the exported API. This local host does not implement write operations, delegated execution, model credentials, external publication, or independent review authority.
