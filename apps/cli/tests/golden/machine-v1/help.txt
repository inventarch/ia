==> ia scope --help <==
ia scope  Issue a read-only scope, or narrow one by phase or identities.

Usage
  ia scope [--root <workspace>] [--params <JSON|->]
  ia scope --schema

Issue a read-only scope or narrow an existing scope by phase or identity set;
its root narrows only where sources declare a reach. Pass its token as within to
later calls in the same process.

Parameters (the --params JSON object)
  within      string. Parent scope token issued earlier in the same process;
  omitted, the parent is the initial boundary.
  root        string. Workspace-relative location the new scope resolves from:
  the parent's root or a directory below it. A source is admitted where its
  declared reach covers this location, and the default empty reach covers every
  location, so this is not a path filter.
  phase       one of orient | plan | act | learn or null. Phase to bind the new
  scope to; omitted keeps the parent's phase, and null binds none.
  revision    string. Asserts the parent scope's revision; any other value
  refuses with IA-DB-SCOPE-MISMATCH.
  identities  array of string. Identities the new scope admits; it stays inside
  the parent's boundary.

Result
  The scope: {token, root, revision}, plus phase when one is bound.

Refusals
  IA-RUNTIME-REQUEST-INVALID         Exit 2. A parameter is unknown, missing or
  of the wrong type. Match the parameters to this operation's schema; the
  message names what was expected.
  IA-DB-SCOPE-UNAVAILABLE            Exit 1. within is a token this process did
  not issue. Omit within, or pass a token issued earlier in the same process; a
  CLI token ends with its invocation.
  IA-DB-SCOPE-MISMATCH               Exit 1. revision differs from the parent
  scope's, or root lies outside the parent's root. Omit revision or pass the
  parent's, and choose a root at or below the parent's.
  IA-GRAPH-COORDINATE-VALUE-UNKNOWN  Exit 1. A phase or coordinate value is
  outside its closed set, or coordinate names an unknown axis. Use one of the
  values or axes the message lists.

Example
  ia scope --root <workspace> --params '{"identities":["governance-system/definition/procedure/sample-procedure"]}'

==> ia context --help <==
ia context  Deliver the cited procedure cells and governance that apply to a
coordinate.

Usage
  ia context [--root <workspace>] [--params <JSON|->]
  ia context --schema

Deliver cited IA procedure cells and applicable governance for a declared phase
and primitive. Budget.tokens counts delivered text and purpose, not the whole
JSON response. Blocking obligations cannot be silently budgeted away. Narrow
topical context with the search and scope operations.

Parameters (the --params JSON object)
  within      string. Scope token issued earlier in the same process: one CLI
  invocation, or the MCP server process. Omitted, the call reads the initial
  boundary.
  text        Required. string. The request in plain words; may be empty.
  coordinate  Required. {shape, category, phase, primitive, move, kind, lane,
  predicate, artifact-set, severity, provenance}. Where the work stands. phase
  and primitive are required; each further axis narrows what applies.
  subject     string or {kind, identity, fragment} or {kind, discriminator,
  name, fragment}. The record the request is about: an identity or a typed
  reference.
  follow      array of string. Relationship verbs to follow from the delivered
  records.
  revision    string. Asserts the scope's revision; any other value refuses with
  IA-DB-SCOPE-MISMATCH.
  ranking     one of native | topical. Default native preserves procedure-first
  ordering. Topical prioritizes scoped search relevance after reserving all
  blocking governance; it does not affect execution selection.
  budget      {tokens, records}. Delivery limits; default {tokens: 4000,
  records: 50}.

Result
  A cited packet: {revision, scope, coordinate, included, omitted, followed,
  gated, dangling, limits}. included holds the delivered cells with their
  citations; omitted names what the budget, a disqualifying condition or an
  unresolved reference left out.

Refusals
  IA-RUNTIME-REQUEST-INVALID         Exit 2. A parameter is unknown, missing or
  of the wrong type. Match the parameters to this operation's schema; the
  message names what was expected.
  IA-DB-SCOPE-UNAVAILABLE            Exit 1. within is a token this process did
  not issue. Omit within, or pass a token issued earlier in the same process; a
  CLI token ends with its invocation.
  IA-DB-SCOPE-MISMATCH               Exit 1. revision differs from the scope's
  own. Drop revision or pass the scope's own.
  coordinate-incomplete              Exit 1. coordinate lacks an axis this
  operation needs; missing names each one. Declare every axis in missing on
  coordinate.
  IA-GRAPH-COORDINATE-VALUE-UNKNOWN  Exit 1. A phase or coordinate value is
  outside its closed set, or coordinate names an unknown axis. Use one of the
  values or axes the message lists.
  IA-GRAPH-VERB-UNKNOWN              Exit 1. follow names a verb the language
  does not define. Use the verbs the message lists.
  IA-RUNTIME-BUDGET-INVALID          Exit 1. budget.tokens or budget.records is
  negative or not a safe integer. Pass nonnegative integers, or omit budget for
  the default.
  IA-GRAPH-BUDGET-BLOCKING-OVERFLOW  Exit 1. The budget cannot hold every
  applicable blocking obligation; required gives the minimum. Raise budget to at
  least required, or narrow the scope.

Example
  ia context --root <workspace> --params '{"text":"author a record","coordinate":{"phase":"orient","primitive":"Decision"}}'

  revision      string. Asserts the scope's revision; any other value refuses

  candidates    Required. array of string. Identities to choose among.
  requiredAxes  array of one of shape | category | phase | primitive | move |
  kind | lane | predicate | artifact-set | severity | provenance. Further
  coordinate axes the request must declare; a missing one refuses with
  coordinate-incomplete.

  coordinate.
  IA-GRAPH-COORDINATE-VALUE-UNKNOWN  Exit 1. A phase or coordinate value is
  outside its closed set, or coordinate names an unknown axis. Use one of the
  values or axes the message lists.
  no-candidate                       Exit 1. No candidate is admitted in this
  scope and applies to the coordinate. Pass candidates that apply; context lists
  the procedures that do.
  deny-wins-tie                      Exit 1. Candidates tie on step, score and
  band. Declare more coordinate axes so one applies more specifically, or pass
  fewer candidates.

Usage

  not issue. Omit within, or pass a token issued earlier in the same process; a
  CLI token ends with its invocation.
  IA-DB-SCOPE-MISMATCH               Exit 1. root, phase or revision differs
  from the scope's own value. Drop the binding or pass the scope's own value. To
