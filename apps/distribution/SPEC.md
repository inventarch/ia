# @inventarch/distribution

Public language mechanism. The [language reference](LANGUAGE.md) defines vocabulary and evaluation limits. Package exports describe the installed API. Curated agent methods and hosted services are supplied independently.

The [installed system-package API](references/system-package.md) verifies explicit per-system native ownership and exact selected dependencies without executing package code.

The host projection mechanism (`./projection`; 2026-10-09, milestone position-packet task replace-renderers, plan amendment B9) plans and applies the files a caller renders, each carrying the marker the caller passes, at the exact `PROJECTION_PATHS` of each host: `.claude/rules/ia-workspace.md` and `.claude/skills/ia-authoring/SKILL.md` for Claude, `AGENTS.md` and `.agents/skills/ia-authoring/SKILL.md` for Codex. No `.claude/agents/*.md` file is written any more. Besides the caller's marker, the two 1.x markers (`<!-- Generated by tools/projections/generate.ts; edit the cited native records. -->` and `<!-- Generated by ia host; edit the cited native records. -->`) are owned, so a file a 1.x renderer wrote is replaced in place rather than refused. The ownership state format `ia.host-projection-state.v1` is unchanged, and a Claude state may still list `.claude/agents/<name>.md`, for removal only: the planner plans `remove` for each listed one that carries an owned marker and is unedited (a listed one already gone only leaves the state), refuses a listed marked one edited by hand as it refuses any owned file, and lists every other agent file, a listed unmarked one and any the state does not list, marked or not, as `foreign`, which no apply writes or deletes. The final state lists only the files rendered. `observeProjection` reports no drift for a listed steward file that is gone or unmarked. The CLI's `applyHostProjection` is the one caller that applies these plans; the steward-guard registration it retires first is `./guard-registration`'s removal, unchanged.
