# @product

Select a product for stable domain identity associating work plans. Workspace,
distribution, contract and individual work words retain their distinct meanings.
Required: meaning.says/answers; product.format number 1, title text, status one of
proposed/active/retired, owner reference to agent, plans list of plan references.
Optional description is text. Computed readiness and service roles are not fields.

Generic native admission enforces required fields, closed shape, status values and
reference target word. Format equality, nonempty title, duplicate plan references
and actual resolution are product-reader checks. Dangling-reference warnings are
not a successful product read. Record identity remains the native system/kind/facet/
name identity; title or service workspace ID cannot substitute.

Author instances under an adopting consumer system with direct required owners.
Never register another product word, mutate the installed base or treat owner as
authenticated membership. Retired preserves identity/history; service effects need
separate current authorization and explicit lifecycle policy.
