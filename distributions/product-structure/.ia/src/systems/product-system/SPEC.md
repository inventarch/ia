# Product architecture

product-system owns one public structural word and its schema, steward and guide.
It depends directly on agent/work owners for fields, compliance for schema,
workspace for release roots and authoring for guide metadata. The separately packed
release externalizes those foreign systems to inventarch/language. Canonical
language and foundation do not gain this registration implicitly.

The independent consumer resolves actual agent/plan identities from an admitted
snapshot; it does not parse IA text itself. Application mappings and retirement
policy consume the same native identity and stay outside this package. Definition
status does not run effects or change access rights. Consumer-local systems may
reference products, but may not shadow their owner or patch this base schema.
