# @inventarch/graph

The pure graph layer consumes compiled IA records and an explicit registry. [SPEC.md](SPEC.md) owns behavior and implementation status. The package provides immutable graph construction, reach/phase authority resolution, occurrence and relationship indexes, a derived typed field-reference index kept apart from the edges, revision hashing, and coordinate/dimension validation. Conditions, selectors, variant and cell selection, and scoped breadth-first traversal consume those products. search(graph, text, scope) ranks decoded content using BM25 with scope-local statistics. The canonical JSON codec (`canonical`, `digest`, `copy` and `CodecError`) gives release assessment and session journals one byte-stable SHA-256 digest; SPEC G12 states its rules and refusal codes. Each loaded Node carries `digest`, the per-record digest `recordDigest` computes over what the record says without where it was read: its source path, lines, spans, placement and provenance (SPEC G13); it is not a revision input.

The package depends on @inventarch/language and uses node:crypto only for deterministic SHA-256. It performs no filesystem I/O, clock reads, source parsing, cache publication or model/tool execution. Decoded prose search is implemented here; IA lexical analysis stays in language.
