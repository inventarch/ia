# Graph specification

Bounded traversal extension (Workbench): optional `maxNodes`/`maxEdges` retain normal authority, scope, direction and condition behavior while bounding emitted records and edge examination. A bounded result reports `truncated`; callers must not describe it as a complete graph. Calls without limits preserve the original contract.

Status: G01–G11 implemented under the graph plan; G12 states the canonical codec re-homed here from session-system; G13 adds the per-record digest; G06b adds the directed view; G06c adds the claimant index and the path-selection dialect. Shared concepts: graph/matrix design. Pure Node-compatible package depending only on @inventarch/language; no filesystem, clock, default registry or source-text lexer. Task-delivery paragraphs below retain historical counts and next steps; current readiness covers the completed downstream consumers.

## Construction and revision

G01. `load(records, registry, options)` returns an immutable Graph containing source diagnostics. Options explicitly supply revision sources, language version, kernel digest, view location and optional phase. A revision source has path, text and Location. `revisionOf` SHA-256 hashes sorted canonical source paths/raw text/placement/provenance, stable registry serialization, language version and kernel digest. Any byte or semantic input change affects the revision. Location/phase identify a view and do not change corpus revision. Duplicate source paths and inconsistent caller-supplied registration/identity/placement are TypeErrors, not authored syntax diagnostics.

G02. Graph snapshots all inputs and exposes read-only collection views backed by inaccessible copies; casting a ReadonlyMap to Map must not make mutation possible. Nested record/schema/registry arrays and objects are frozen copies. `serialize(graph)` has total stable ordering independent of source, record and map insertion order. Object keys sort by code point, maps by serialized key, sets by serialized value. Source text is revision input, never re-lexed here. SHA-256 uses the pure deterministic node:crypto hash API.

G03. Canonical reach/location roots are corpus-relative paths using language canonicalPath with an empty-root sentinel. Above-root traversal or absolute roots are usage errors. Empty reach covers every location; a nonempty reach covers itself and segment-boundary descendants only. Validate each record's placement kind/band pair. Provenance never determines authority.

## Authority and indexes

G04. Filter occurrences by reach and optional phase before authority. For phase applicability, any selector group without a phase term admits every phase; otherwise the record admits the union of its groups' phase values. No selectors or an omitted phase imposes no phase filter. At each identity the unique highest-band applicable occurrence wins. A highest-band tie refuses every tied participant with IDENTITY-TIE and admits no lower fallback. Differing overlapping reaches do not break ties. Retain all source occurrences, explicit shadows and ties separately; nodes is a winners-only identity map. Out-of-reach/phase occurrences remain inspectable but unindexed.

G05. Build byName, byDiscriminator, byKind, bySystem, byCategory and byLane postings from winners; category comes from the registration and lane from the validated kernel kind mapping (contract@authority maps authority). Index cells at phase/primitive, selector axis/value groups and all condition terms from cells/edges/variants/requirements. Classification is an optional single head artifact-set field, a scalar/string closed value. Severity is an optional single governance.severity scalar/string closed value. Unknown, malformed or repeated dimension declarations refuse that record with DIMENSION-UNKNOWN. Provenance is the compiled loader-supplied value. Prose/gloss fields never supply routing coordinates.

G06. Resolve every authored edge through language.resolveTarget against winners, including formerly dangling edges. Normalize inverse direction into active endpoints; retain author identity, typed reference, fragment, condition subject (the author), spans and source assertions, each assertion keeping the verb `spelling` its author wrote while the edge's endpoints stay active (a registration-generated ground assertion carries `ground`; under language S07 it absorbs an equivalent unconditioned, fragmentless ground line written on the same system record in either outbound spelling, `ground` or `grounds`; any other ground line, such as `grounded-by @system <name>` on the schema, keeps its spelling and ordinary consent under G07). A missing endpoint is null: ordinary edges remain under out[author], inverse edges under in[author]. Both forms remain in dangling and a byDanglingReference index. More than one candidate refuses the edge with TARGET-AMBIGUOUS; zero retains it with TARGET-MISSING warning. Resolve API reports these graph codes without candidate-order selection. The directed view (G06b) reads each resolved assertion from both endpoints, as declared on its author and as a derived inverse on the other side; a dangling assertion has no row there.

G06a. Derive `references`, a typed field-reference index beside the edges, from every typed ref value a winner holds in its head or sections, list items and nested fields included. Each `FieldReference` carries `from` (the holder), `to` (the resolved winner), `field` (the compiler's field path: `head.steward`, `composition.mandate`, `binding.target`, or the bare section name for a section-level item), the authored `reference` and the holder's source span. Targets resolve through the same resolve API as edges; an unresolved or ambiguous ref is omitted without a graph diagnostic, because compliance reports it (IA-COMP-FIELD-REF-MISSING). The `relationships` section is skipped by name, so a consent-refused assertion never reappears as a reference, and a ref inside the span of an edge the compiler already lowered (a floor `@system` `discriminators` entry's `ground`) is skipped, so no authored ref is both an edge and a reference. A field reference carries no predicate and is never consent-, cardinality- or COMP-checked; `edges`, `in`, `out`, `dangling`, diagnostics and revision are unchanged by it. `referencedBy` keys `references` by target and `referencesFrom` keys them by holder, each list in `references` order, both built once at load. Ordering is total over from, field, to, source path/line and the serialized reference, independent of input order; equal entries are stored once. The directed view (G06b) lists each reference from both ends as a derived `field-ref` row, so the index is navigable from its holder as well as its target.

G06b. `directedView(graph, identity)` returns the identity's directed view (position-and-projection row 4 and section 8): a frozen list of every row the graph holds at that identity, read from its side. Each resolved edge the identity is an endpoint of gives one row per assertion per side it occupies, carrying the edge's `predicate`, the `direction` the identity reads it in (`out` at the active source, `in` at the active target), the `counterpart` (the other endpoint), `declaredOn` (the assertion's author), `declaredBy` (`source` for an outbound assertion, `target` for an inverse one, the same from either side: the `declared by source` or `declared by target` label), the assertion's `source` lines, and the edge's `fragment` and `condition` when it has them; the fragment addresses the record the declaration references. On the side its author stands the row is `kind: 'edge'`, `derived: false`, with `spelling` the verb the author wrote. On the other side it is `kind: 'inverse'`, `derived: true`, with `spelling` the kernel's for that side: the active predicate at the source, and at the target its language `INVERSE_OF` spelling, one of the eighteen (governed-by, enforced-by, grounded-by, constrained-by, implemented-by, produced-by, consumed-by, lineage-recorded-by, access-granted-by, run-after, triggered-by, cited-by, superseded-by, required-by, used-by, forbidden-by, routed-by, landed-by). An edge asserted from both ends keeps both assertions (G07), so each side holds its own declared row and the derived inverse of the other's; a self-relation is read from both of its sides. Each G06a field reference the identity holds or is named by gives one `kind: 'field-ref'`, `derived: true` row with its `field` path, `declaredOn` the holder and no predicate or spelling. A derived row is a view and is never authoritative over the declared row it reads: nothing is written back to source, merged into `edges` or re-spelled there. Dangling (G06), ambiguous and consent-refused (G07) assertions are findings, not rows: a dangling one stays in diagnostics, `dangling` and `byDanglingReference`, an ambiguous or refused one in diagnostics only, and neither endpoint has a row for it. An identity that is not an admitted winner has no rows. Rows order by kind (edge, inverse, field-ref), direction (out, in), predicate or field, counterpart, declaring record, source path and line, then the serialized row: a total order independent of input order. The view is computed on read from the load-time `out`, `in`, `referencesFrom` and `referencedBy` indexes, so a call reads only the identity's own entries and never scans `references`; reading it adds no index, diagnostic or revision input and leaves `serialize(graph)` unchanged. `tests/directed.test.ts` pins both spellings from both sides, both-sided assertions, self-relations, fragments, conditions, findings, field references and the order within one kind and direction, and that over the native corpus each resolved assertion and each field reference is read exactly once from each end, a record's held references exactly as a scan of `references` finds them.

G06c. Claimant index and path selections (position-and-projection row 17; the covers-field-vs-predicate decision keeps `covers` a field of text path selections, neither a predicate nor a ref). `claims` is a derived index built once at load: one frozen `Claim` `{from, field, selection, source}` for each text value a winner holds in a claimant field, a list's items in authored order. The claimant fields, exported as `CLAIM_FIELDS`, are `authority.covers` (`@mandate`), `subject.covers` (`@law`, `@convention`), `work.covers` (`@spec`), `hook.paths` (`@hook`) and `check.scope` (`@check`), each a top-level field of its section, read by path on any winner that holds it; schema admission keeps an undeclared one out of an admitted view. A nested field, a ref value and a `covers` in any other section are not claims. Equal (holder, field, selection) claims are stored once, and claims order by holder identity, then as the record states them. A claim is not an edge: it carries no predicate, is never consent-checked and is not a revision input. `selects(selection, path)` is the one path-selection dialect. Both read `\` as `/`. The path is canonicalized as a scope root (G03: `.` and empty segments dropped, `..` resolved), and an absolute path or one escaping the workspace is selected by nothing. A selection is `/`-separated workspace-relative segments: a whole-segment `**` matches zero or more segments, `*` any run of characters within one segment, `?` exactly one character (one code point), and every other character itself, case-sensitively. A trailing `/` stands for `/**`, so `docs/` selects `docs` and everything below it, while `docs` selects only that path. There are no braces, classes, escapes or negation, a leading dot is not special, and an empty or absolute selection, or one with an empty, `.` or `..` segment, selects nothing; a prose `check.scope` selects at most the one path it spells. Matching keeps one backtrack point per level, so it takes at most pattern × path steps. `claimants(graph, path, scope?)` reads the index, never the records: each winner with a claim that selects the path, holders outside `scope` pruned, as a frozen `Claimant` `{identity, band, matches}` listing every matching `{field, selection}` in index order, ordered band descending then identity ascending. `tests/claims.test.ts` pins the dialect, the index over probe and native records, permutation stability, pruning and the order.

G07. Check both word owners' consent on each resolved edge in active direction, reporting only the first refusing side as EDGE-UNCONSENTED. The exact unconditioned, fragmentless system-to-registered-schema ground assertion generated by registration bypasses ledgers as specified by language S07; no other ground edge is exempt. Store equivalent unconditioned edges once, retaining every source assertion. Conditioned edges also key by condition subject, because equal terms authored on different records may see different dimensions. Sort edges by endpoints/predicate/fragment/condition/author/source for a total order.

G07a. Reuse language S07a's fixed incoming whole-schema citation permission when an edge resolves across inputs. Pass the actual logical target endpoint's fragment to consent, preserving inverse references on the other endpoint. The source ledger remains required; missing/ambiguous targets retain their existing outcomes. No additional ground or authority exemption is introduced.

A fragment still addresses the originally referenced record after inverse normalization. Edges therefore retain fragmentEndpoint (from for an inverse assertion, to for an outbound assertion), preventing an inverse fragment from being misapplied to its author.

## Coordinates and queries

G08. A graph coordinate is a partial mapping of closed routing axes plus severity/provenance to values. validateCoordinate canonicalizes case-insensitive values using language tables and rejects unknown names/values as COORDINATE-VALUE-UNKNOWN. Public query methods reject invalid coordinates with a typed GraphUsageError. Missing routing axes cannot satisfy conditions. Conditions read severity as max(subject severity, request severity), provenance from the subject, and artifact-set from its classification; other axes come from the request. Selector terms, including artifact-set, match the request. No default dimensions are invented.

G09. selectors(record, coordinate) reports matched, neutral or disqualified. Groups are OR; terms within a group are AND. A fully supplied matching group establishes matched with its maximum term count. No selectors or an uncontradicted group with missing values yields neutral; all groups contradicted by at least one supplied value yields disqualified. This affects retrieval, never parses a meaning gloss. variants selects the highest-specificity applicable clause in each key family; equal maxima report VARIANT-AMBIGUOUS and select none for that family. A conditional exact cell that does not apply cannot suppress a valid primary fallback. Cell selection returns exact, primary or absent for one record/coordinate.

G10. traverse(graph, options) performs breadth-first traversal from a declared start list. follow verbs use the exact language table and imply direction; direction is consulted only if follow is absent. Depth is an integer 0..8, otherwise TRAVERSAL-INVALID. Unknown verb is VERB-UNKNOWN. Scope is an allowed identity set and prunes starts, endpoints and traversal; an out-of-scope intermediary cannot expose its descendants. A filter prunes nodes by kind/discriminator/system using typed data. Missing starts yield no walk. Cycles terminate. With a coordinate, false conditions go to gated and are not crossed/returned as followed; without one, conditioned edges may be traversed with their conditions retained. Expose dangling separately. Nodes order by depth/identity, via by from/predicate/direction/target, edges by G07's total order.

G11. search(graph, text, scope?) is graph-owned BM25 over decoded names, field/item text, references and semantic products without indexing the same body text twice. Preserve donor NFKC/lowercase/NFD mark removal, Unicode letter/digit tokens of 2..64 characters, donor stopwords, k1=1.2 and b=.75. Query terms deduplicate. Statistics N/df/average length are computed over the allowed scope, never hidden records. Return positive scores sorted descending then identity. Text tokenization is over decoded prose/query strings, not IA source syntax. Expose no mutable postings.

## Canonical codec

G12. `canonical(value)` is the canonical JSON text of finite structured data, the digest contract that release assessment, captured compositions and session journals share. It admits null, strings, booleans, finite numbers, arrays and objects whose prototype is `Object.prototype` or null, and reads only own enumerable string keys. Members are written in UTF-16 code-unit order of their keys, except that array-index keys lead in ascending numeric order, as JavaScript property order requires; values are written as `JSON.stringify` writes them, with no whitespace. Any other value (undefined, a non-finite number, a bigint, function or symbol, or an object with another prototype such as a Map, Date or class instance) refuses with IA-SESSION-INPUT-INVALID, as does a `__proto__`, `prototype` or `constructor` key. A value more than 64 levels below the root refuses with IA-SESSION-LIMIT-EXCEEDED whatever its kind, so a cycle through otherwise valid data refuses with that code. `digest(value)` is the lowercase hex SHA-256 of the canonical text's UTF-8 bytes. `copy(value)` parses the canonical text back: a new value of arrays and `Object.prototype` objects with keys in canonical order, refusing exactly what `canonical` refuses. Every refusal is a `CodecError`, an `Error` named `CodecError` whose readonly string `code` is the stable contract. Canonical text and digests are byte-stable: vectors captured from the session-system codec before it moved here pin both. The codec is distinct from `stableSerialize`, which tags maps and sets and feeds `revisionOf`; neither replaces the other. `@inventarch/session-system` re-exports this `CodecError` class and wraps `canonical`, `digest` and `copy`, rethrowing each refusal as its `SessionError`, a `CodecError` subclass named `SessionError`, with the same code and message.

G13. Every Node carries `digest`, its per-record digest, computed once per occurrence at load by the exported `recordDigest(record)`: the G12 `digest` of a location-free form of the compiled record. The form covers identity, system, kind, facet, name, displayName, discriminator and parent (null when absent); head and section fields and items, in authored order, each one row of its `path` of indexes among its parents' children with its key, value and `when` words, or its item, so nested blocks are covered and the form's depth stays bounded however deeply they nest; each compiled edge's predicate, direction, spelling, typed reference, fragment and condition; cells (phase, primitive, primary, text, condition), selectors, variants (key, value, condition) and requirements (id, kind, text, condition); and schema. It omits where the record was read: `source` (path, line, endLine) and every field, section and product span; `placement` (kind, band, reach) and `provenance`, which the loader supplies from the source's location rather than the record's text (G05) and which database capture membership carries as root and band; and each edge's compile-time `target`, which resolves against the other records of its file rather than anything the record says. Inserting, editing or removing another record, comment or blank line, moving the record to another file, or reading the same text at another placement and provenance (an adopted or installed mount rather than the authored tree) therefore leaves its digest unchanged, while any change to what it says changes it. The digest is over the compiled form, so a vocabulary change that changes how the same text compiles (a schema spelling that resolves a field key, a registration that generates a floor ground edge only where it registers) changes it too. Every compiled record fits the G12 nesting limit, so computing the digest never refuses. It lives on the Node because language cannot depend on this codec. It is not a `revisionOf` input, so graph and workspace revisions are unchanged; `serialize(graph)` includes it. `tests/digest.test.ts` pins one vector and both directions.

## Diagnostics, evidence and boundaries

Graph source codes use IA-GRAPH-IDENTITY-TIE, TARGET-MISSING, TARGET-AMBIGUOUS, EDGE-UNCONSENTED and DIMENSION-UNKNOWN. Query errors use IA-GRAPH-COORDINATE-VALUE-UNKNOWN, VERB-UNKNOWN, TRAVERSAL-INVALID and VARIANT-AMBIGUOUS; root normalization uses SCOPE-INVALID. Codec refusals use IA-SESSION-INPUT-INVALID and IA-SESSION-LIMIT-EXCEEDED (G12). Source diagnostic shape matches language with the graph namespace; errors refuse their stated subject, warnings retain evidence. Fragments are retained but compliance owns existence. Graph performs no scenario execution, caching, scope-token issuance, ranking into runtime packets or model/tool dispatch. Public evidence must distinguish these boundaries.

Each task records native success/refusal, permutation/immutability and public-consumer evidence here. Native taxonomy/system records, the authoring playbook, law and check provide the normal path; overlays and malformed coordinates provide adversarial cases. Central exact-cell/primary examples use separate records to avoid double-delivery. Raising severity uses an advisory fixture, because a blocking subject is already blocking without a request override.
