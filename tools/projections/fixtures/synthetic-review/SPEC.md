# Synthetic prose review fixture

This public fixture contains original fictional content and no vendor prose. Its
zero-new-word system requires adopted agent, governance and composition definitions.
`fictional-review-steward` owns maintenance; the distinct `fictional-reviewer` is the
agent export. A profile composes its voice, mandate and capability, while the skill
and explicit command share a conditional review method and two linked resources.
There is no harness or executable binding.

Author changes in `prose.ia`; use native schemas supplied by the adopted foundation.
Keep the system's single steward and direct dependencies. Guides are captured by
explicit file pins and associated with exact admitted capability occurrences.
The fixture tests adopt this physical source tree and independently scope retrieval.
No local copy of the adopted vocabulary is authored into this system.

Positive observation: a note naming its owner and measurable outcome can receive a
cited prose assessment. Misuse observation: the generated rule cannot establish a
machine check, tool permission or fresh-agent success. Package tests and isolated
consumer qualification own the actual admission, generation and refusal evidence.

The same capture and three exports exercise both prose profiles. Claude emits an
agent, skill and command. Codex emits a native workspace agent with registration,
or an explicit-only plugin role skill as selected by the operator; its explicit
command is a skill with implicit invocation disabled. Both preserve the native
closure and exact linked resources. Host discovery and static parsing are distinct
from live model execution and installed lifecycle acceptance.
