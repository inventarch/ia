# Complete task capture

The root exports `prepareTaskCapture`, `verifyTaskCapture`, `taskCaptureRequest`, `TaskCaptureError` and their types. A host supplies a complete authorized native/resource/index view, a current-state check, and a `resolveTaskContext(request)` callback selecting an already reviewed declaration. Remote requests still contain only the exact work identity and phase/primitive. Missing host authority refuses.

The closed `TaskContextDeclaration` binds exact task and made grounding-decision occurrences, the explicit coordinate, affected native source paths, complete existing authoring requests (including document/lifecycle applicability) and any extra required resources. A null document or lifecycle is the host's affirmative declaration that it is inapplicable. It is never inferred from a missing check. Neither the declaration nor a made status is a write grant.

The fixed policy retains global/unscoped governance and any governance that existing native selectors cannot definitively disqualify using the declared coordinates. Missing coordinate axes do not justify omission. It adds required schema, registration, owning-system and teaching context. Required authoring inputs use the existing guide, artifact, document-role and lifecycle semantics.

Prerequisites and typed parent references are followed outward. Governing, constraining, forbidding and enforcing records are followed inward, as are made decisions grounding selected work. Supersession retains history and an unambiguous successor without replacing the selected task or granting current authority. A stale basis, conflicting successors or cycles refuse. Reverse prerequisites, milestone siblings and cited-by records are not automatically relevant.

Selection retains whole native files and every authored relationship endpoint and outgoing typed reference from co-located records, including inverse assertions and nonblocking citations. Enclosing system declarations are retained independently of the registration owner. Empty omitted system folders do not remain as fabricated source observations. It preserves the complete native floor and competing resolution occurrences. Every omission includes its original hash and policy reason. There is no prose ranking, record slicing or silent truncation. Unknown source bytes remain conservative.

Compiler-required contract case producers must be explicit authoring targets when the closure depends on them; selection does not infer every incoming implementation is relevant. Missing coverage refuses admission.

Only positively required resource/index associations are retained. Complete selected document membership remains intact; expected outputs are not fabricated as inputs. Extra resources supplement computed teaching and cannot subtract from it. Re-admission must preserve all retained winner bytes, relationship completeness and required authoring semantics.

A version-2 capture pins the declaration digest, policy, implementation, full source/resource/index, selected teaching and closure proof. The exact known historical policy remains readable, but current admission requires a fresh reviewed declaration and recomputation. Unknown policy implementations fail closed. Whole-workspace version-1 capture remains unchanged. Disclosure includes the reviewed declaration and every selected/omitted file and required resource pin. Client and receiver must select byte-identical implementation files (absolute install paths may differ). Development source, a different compiled release or a bundled build is not implicitly compatible. A trusted bundled host may supply its verified matching artifact digest; no caller digest or compatibility allowlist is accepted. Mismatched implementation bytes produce the distinct implementation refusal before closure recomputation. The receiver must recompute using its own current trusted full view and declaration; accepting a caller's subset or digest as completeness is unavailable.

The exact serialized native capture, including scope metadata, must fit **716800 bytes**. A smaller caller limit is allowed; widening is unavailable. Resources and disclosure retain their separate existing limits. Required overflow records the measured size and proof. Freshness covers excluded files, authoring metadata and the declaration itself.

Compose complete authorized personal/project views before selection. Mounting a selected subset refuses so that composition cannot erase scope. This is task-context preparation; private whole-corpus review, effect authority, authentication, grants and execution budgets remain independent.

A real task may still overflow this policy. Such a refusal describes this declared closure, not a minimum size across all imaginable policies. Synthetic or installed checks do not establish a deployed host's authority or whole-product release readiness.
